# Cost estimate

Cloud development and local tests need no paid AI calls. Open-source tool dependencies require no license purchase. Initial incremental cash target is RM0–500 excluding existing hardware and labor; this is a target, not a guarantee. Customer local inference depends on hardware and model license. Optional cloud inference, Windows code signing, distribution, hosting and custom integration costs must be priced separately. No cloud GPU or paid database is required by this foundation.

Phases 5–8 add no cloud GPU or paid database requirement. Local browser automation and worker tests use the existing cloud CPU/browser; no paid AI/payment call was made. A small separately hosted authority is needed for trustworthy commercial licensing/credits, and operational hosting, backups, payment fees and Windows code signing are separate costs. A production certificate may exceed the initial RM0–500 development cash target; do not claim it has been purchased or included. GitHub Actions usage depends on the account's free/minute allowance. Unsigned development installers are not substitutes for signed production releases.
