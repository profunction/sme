# Cost estimate

Initial prototype target: RM0–500 incremental cash, excluding developer labor, existing phones/computers, optional development subscriptions and future store/developer accounts. Current Phase 1 makes no AI calls, runs SQLite and formats PDFs deterministically. It needs no GPU, vector database, Kubernetes, paid database or mandatory microservices.

Local development may cost RM0 on existing hardware. A small HTTPS host plus domain/backups is an owner-dependent expense, not a quoted price or a purchased resource. No server or payment account is provisioned automatically. GitHub runner usage and artifact retention are subject to the repository account's terms.

Future cost controls: document retrieval and response caching before inference; small models for simple structuring; per-company/user quotas and transactional cost reservations; bounded retries/tool calls/storage; separate consent for voice and photos. No dollar amount is promised for unmeasured model use. Device Ollama is optional future inference; it is not bundled or required by this Phase 1 app.
