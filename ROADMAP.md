# Roadmap

1. Current: desktop shell, chat, SQLite, local/cloud provider adapters and automated API tests.
2. Hardware inspection, measured local model benchmarks, hybrid routing, BYOK vault and usage accounting.
3. Deterministic Excel/PDF/Word tools, task history and approvals.
4. Connector registry, generic REST and explicitly labeled mock ERP/POS/WMS/TMS.
5. Browser and Windows UI Automation with cancellation and verification.
6. Employee roles and scoped permissions.
7. Trusted subscription backend, quotas and credits.
8. Bundled backend, signed Windows installer, secure updates and Windows integration tests.

Only Phase 1 is implemented. No real vendor integration is claimed.
